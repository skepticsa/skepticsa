# Danut Prisacaru

Principal Architect in Austin, Texas. I work on the architecture of AI systems: how to evaluate them, how to scale them and what to build. I work in Python, Terraform, SQL and AWS.

## What is here

- [local_rag_claude](https://github.com/skepticsa/local_rag_claude): a local RAG system. Embeddings run on Apple Silicon, retrieval is cosine similarity over persisted vectors, generation goes to the Claude API, and every call is logged with token counts and cost.
- [aws-chat-with-files-bedrock-kendra](https://github.com/skepticsa/aws-chat-with-files-bedrock-kendra): Terraform for a document chatbot on AWS (S3, Kendra, Bedrock, Lambda, API Gateway, CloudFront, WAF).
- [ec2_claude_ai_code](https://github.com/skepticsa/ec2_claude_ai_code): Terraform for a bastion host built to the Well-Architected Framework, with the design decisions and the monthly cost written down.
- [sal](https://github.com/skepticsa/sal): Software Abstraction Layer, an architectural style I wrote up in 2021.

The rest are course projects from the Udacity AWS Machine Learning Engineer Nanodegree and older experiments, kept as a record.
